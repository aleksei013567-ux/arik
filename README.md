# 🗨️ Forum — Лёгкий форум на чистом PHP + Bootstrap

> 🚀 Простой, но полностью функциональный форум для обучения и быстрого старта. Написан на чистом PHP без фреймворков, с адаптивным дизайном на Bootstrap и хранением данных в MySQL.  
> ⚠️ **ВАЖНО: Для работы проекта требуется база данных MySQL — структура прилагается в `forum.sql`.**

---

## 📖 Описание проекта

Forum - это реальный, готовый к запуску форум, который:

✅ Работает сразу после импорта БД и настройки конфига
✅ Позволяет создавать темы и просматривать их в браузере
✅ Имеет адаптивный дизайн — красиво выглядит на любом устройстве
✅ Не требует сборки, npm, Node. js или сложных зависимостей


💡 **Проект подходит для** 

Общение — по интересам, профессиям, хобби.
Помощь — ответы на вопросы от сообщества.
Обмен опытом — советы, инструкции, лайфхаки.
Поддержка — эмоциональная или техническая.
Сообщество — чувство принадлежности к группе.


> ⚠️ **Внимание**: проект **не включает авторизацию, валидацию, защиту от инъекций** — предназначен для обучения. Для продакшена требуется доработка.

---

## 🛠️ Используемые технологии

| Компонент       | Технология                                  |
|----------------|---------------------------------------------|
| Backend        | Чистый PHP 8.0+                             |
| Frontend       | HTML, CSS, Bootstrap 5.3 (через CDN)        |
| База данных    | MySQL 5.7+                                  |
| Управление БД  | phpMyAdmin (входит в XAMPP, MAMP, Laragon)  |
| Локальный сервер | Встроенный PHP-сервер или XAMPP/Laragon   |
| Стили          | Bootstrap + минимальные кастомные CSS       |

> ✅ **Без Node.js, без npm, без сборщиков** — только PHP, HTML, CSS и MySQL.
